# Website-Test
Test website to learn web development fundamentals

## How to start the Webserver with Python

to start the Server you need to start the app.py to start the Webserver, you can Access the Server with localhost:5000 or 127.0.0.1:5000

## What you need to to before the Server works
You need to set an APIKEY for the API calls inside the app.py

## What files exist

- **index.html**: Main screen - the homepage and entry point of the website
- **about.html**: Currently a placeholder, will later show names of participants  
- **lul.css**: Styling file that contains all the CSS rules for the website's appearance
- **info.html**: Placeholder for later information and additional content
- **app.py**: Flask Webserver for api calls
- **Script**: Folder filled with js files to ex. unpack api calls or change website th
eme color
