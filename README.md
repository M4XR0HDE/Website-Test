# Website-Test
Test website to learn web development fundamentals

## How to start the Webserver with Python

To start a local web server for this project, use Python's built-in HTTP server module:

```bash
python3 -m http.server 8000
```

Then open your web browser and navigate to:
```
http://localhost:8000
```

The server will serve the files from the current directory. You can specify a different port by changing the number (e.g., `python3 -m http.server 3000` for port 3000).
